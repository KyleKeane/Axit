# The runner's keys have no plus or minus key, so Ctrl+Plus and Ctrl+Minus run as their menu items, Options, Text,
# Larger text and Smaller text. The sizes assume the Windows system font at 9 points, which fresh settings start from.
# The run's own settings: no update check, whose network call logs an ERROR when GitHub cannot be reached.

start preview {temp}\README.md
expect focus README.md
# 3.1: larger, "Text size 10", the caret where it was; smaller back.
keys down down
expect state Line 3, Column 1 \u00B7
menu Larger text

expect state Line 3, Column 1 \u00B7
expect focus {"name":"README.md","role":"Text","value":"## Install"}

expect said ! Text size 9
expect state Line 3, Column 1 \u00B7
