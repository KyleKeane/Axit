# axProcess: start, the Processes view, ending a process (docs/axprocess/nvda-test-plan.md sections 1 and 2; SPEC PR-2, PR-3).
# The lists are this computer's, so the steps match the fixed words, never a count. Something safe to end: a hidden
# ping that runs for two minutes with its window hidden, started apart from the runner's command (run's own children
# end with the command, since it reads their output).
file home\Axit\axprocess.json {"checkForUpdates": false}
run powershell -NoProfile -Command "Start-Process ping -ArgumentList '-n','120','127.0.0.1' -WindowStyle Hidden"

# 1.1 The window, and after the first read (one second of sampling) the list's name and first item, not interrupting.
start process
expect state This computer - axProcess
# The list is named "Processes, reading" while the first read runs; the status bar says "Reading…" until it is done.
expect state "status":["Processes,
expect said Processes,
expect focus Processes,

# 1.3 The status bar: the list's name and the memory in use.
expect state "status":["Processes,
expect state % in use

# 1.4 Ctrl+Q: the summary.
keys ctrl+q
expect said GB in use

# 1.5 Nothing is said while no key is pressed: the list never refreshes by itself (PR-D2).
expect quiet 3000

# 1.6 F5: read again, said, the selection kept.
keys f5
