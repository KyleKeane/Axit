# axTerminal, section 1 of docs/axterminal/nvda-test-plan.md: start (AT-1, AT-2). The shell is the default one of a
# fresh settings file: PowerShell 7 when installed, otherwise Windows PowerShell; the texts below name neither.
# Plan step 1 by the Start menu entry stays manual: the Start menu is the system's, outside the window.
# NVDA's own reading of the window's name on opening is tier 3 (NVDA in the loop); here the title is checked.
mkdir myproject
# The run's own settings: no update check, which would go to the network and log an ERROR when it fails.
file home\Axit\axterminal.json {"checkForUpdates": false}
# The access layers' reminders agreed to already (AX-11.5): this script is about what comes after them.
file home\Axit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"},{"app":"axGIT","target":"Git","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Windows PowerShell","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"PowerShell 7","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Command Prompt","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Git Bash","version":"0","when":"2026-10-31T00:00:00"},{"app":"axPass","target":"KeePassXC","version":"0","when":"2026-10-31T00:00:00"}]}
start terminal {temp}\myproject
# The window's command list: every key of its own in the F1 text, none shadowed (docs/axit/app-kit.md AK-2.4).
check commands
# Step 1: the window and the field; after a moment the ping and "Ready".
expect focus Command
expect state "title":"myproject -
expect state - axTerminal, access layer for your shell"
expect said Ready
expect said ♪ Ready

# Step 2: Ctrl+2 lands on the terminal; its first lines are the system line and PowerShell's PSReadLine line; no
# prompt row. Ctrl+1 back to the field.
keys ctrl+2
expect said → Terminal
expect focus Terminal
expect text "System: Shell started:
expect text PSReadLine
# That no prompt row ("PS C:\...>") is in the text cannot be checked: the runner has no "refuse text".
keys ctrl+2
expect said ! Terminal
keys ctrl+1
expect said → Command
keys ctrl+1
expect said ! Command

# Step 3: the status bar holds "Idle" and the prompt text. The state answer is raw JSON, where a backslash is
# doubled and ">" is written \u003E, so the prompt is matched by its ends.
expect state "status":["Idle","PS
expect state myproject\u003E"]

# Step 4: Ctrl+Q says the state, the shell and the prompt.
keys ctrl+q
expect said PowerShell, PS {temp}\myproject>
