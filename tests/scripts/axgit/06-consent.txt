# axGIT: the reminder before the first repository opens (docs/axit/SPEC.md AX-11.4, AX-11.5; the Owed list of
# docs/axit/nvda-test-record.md). A fresh run's home has no consent, so the reminder comes first. With --nvda
# (nvda-pass.ps1) every expected line must be spoken by NVDA too.
file home\Axit\axgit.json {"checkForUpdates": false}
run git init -q -b main repo
file repo\a.txt hello
start git {temp}\repo

# The reminder's title and text, read on the focus.
expect said Before axGIT connects to Git
# Tab to the box, named with what it agrees to.
keys tab
expect said I understand that axGIT
# Enter before the box is checked connects nothing.
keys enter
expect said ! Check the box first
# Space checks and unchecks, each said (AX-8.8).
keys space
expect said ! checked
keys space
expect said ! not checked
keys space
expect said ! checked
# Enter connects: the repository opens on its Changes list.
keys enter
expect focus Changes, 1 file
close

# The second start asks nothing.
start git {temp}\repo
expect focus Changes, 1 file
refuse said Before axGIT
