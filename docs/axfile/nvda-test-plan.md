# AxFile NVDA test plan

Run with NVDA before a release, on a folder with a few subfolders, text files and sound files (a folder of MP3 chapters, and one `.json` and one `.md`), after `run-axfile.ps1 C:\path\to\folder` (or `.\run.ps1 -App file <folder>`). Every step says what NVDA should read; a step that reads differently is a defect. The specification is `docs/axfile/SPEC.md` (AF-n.m).

## 1. Start and the list (AF-1, AF-2, AF-3)

1. Start AxFile on the folder: NVDA reads "<folder name> - AxFile window", then "N items list, <first entry>, 1 of N" (the folder is not read again). Nothing else is spoken. A folder entry reads "docs, folder".
2. Down Arrow: the next item, nothing else. Home, End: the first and the last. Type the first letter of an entry further down: NVDA reads it. Tab: nothing happens (the list is the one control).
3. NVDA+End: the status bar: nothing on the left, the folder's full path on the right.
3a. In a folder with a hidden file and a `.gitignore` (a git repository will do): End: the last line reads "Not shown: 1 hidden, 1 starting with a period" (your counts); Enter on it: the same line; Up: the last entry. Options, General: "Show hidden files and folders" unchecked, "Show files and folders starting with a period" unchecked; check the second: the list is read again with `.gitignore` in it, the last line "Not shown: 1 hidden"; check the first: the last line is gone. Uncheck both.
4. On a folder, Enter: NVDA reads the first entry of that folder; the title (NVDA+T) names it. Backspace: back in the folder above, on the folder you left. Alt+Up does the same. At `C:\`, Backspace: "This PC, N items, list, Local Disk (C:), drive" (your label for C: if it has one), the title "This PC - AxFile"; Ctrl+I: "Local Disk (C:), <n> GB free of <m> GB"; Ctrl+Shift+N: "Choose a drive first"; Backspace: "Top"; Enter: back at `C:\`. Enter on an empty folder: "Empty, list, No items in this folder, 1 of 1"; Enter, Ctrl+I or F2 on that line: "No items in this folder".
5. Ctrl+I on a file: "<name>, <size>, modified <date time>"; on a folder: "<name>, folder, modified …".
6. On a `.md` file, Enter: a new AxDown window on it (Alt+A, O goes back). On a `.json` file: AxJSON. On a `.pdf` or similar: the program Windows has for it. On a file of a type nothing opens (make `x.axtest`): "No program opens .axtest. Ctrl+E opens it as text"; Ctrl+E: AxDown on it.
7. Ctrl+G: the notice "Go to folder" with the field "Path" holding the current folder; type `%USERPROFILE%\Downloads`, Enter: the list is Downloads. Ctrl+G, type a file's full path, Enter: its folder with the file selected. Ctrl+G, type `C:\nope`, Enter: "Not found: C:\nope".
8. Ctrl+O: the Windows folder picker; choose a folder: the list shows it, the focus back in the list. Folder, Open recent folder: the folders opened by command as "1. name (path)". Ctrl+N: a second AxFile window on the same folder, read as the first was; Alt+A, O, 1 goes back to the first. Ctrl+D: "Added to Favorites"; Alt+F, V: "1. <folder> (<path>)", then "Add or remove this folder Ctrl+D"; Escape, Backspace to the folder above, Alt+F, V, 1: the folder is back. Ctrl+D: "Removed from Favorites"; Alt+F, V: "No favorites yet".
9. In File Explorer, add a file to the folder; Alt+Tab back to AxFile: the file is in the list, on the entry you had, nothing spoken. F5: "Refreshed".
10. Ctrl+F, type part of a name further down, Enter: NVDA reads that entry. F3: the next match, or "Not found". Shift+F3: back.
10a. Ctrl+Shift+F: the notice "Filter" with the field "Name contains"; type part of a name shared by a few entries, Enter: the list reads "3 of N items, filter <text>" and the entries are those alone; Down through them. Ctrl+I: the entry as before. Escape: "Filter cleared", the whole list is back on the same entry. Ctrl+Shift+F, type `zzz`, Enter: "No names contain zzz, 1 of 1"; Enter on it: "No names contain zzz"; Escape. Alt+F, S: "Sort by submenu" with Name checked, Date, Size; D: "Sorted by date", the newest file first after the folders; Ctrl+I on the first two files confirms the dates; N: "Sorted by name".
11. Ctrl+S: "Nothing to save here". F1: the Keyboard shortcuts notice; Escape closes it.
12. Delete the folder shown in File Explorer while AxFile is on it, then Alt+Tab back: the notice "Folder not found" naming it; Enter: the list shows the folder above.
12a. Alt+D: the Drives menu, "1. Local Disk (C:)" (your label), the other drives, then This PC, Eject this drive, Drive properties. 1: the list is `C:\`. Alt+D, P: This PC with "Local Disk (C:)" selected. With a USB stick in: Alt+D, its number: the stick's root; Alt+D, E: "Ejecting <its name>", Windows' "Safe to remove hardware" notice, the list at This PC without it. On `C:\`, Alt+D, E: "Failed: This drive has no Eject". Alt+D, R: the drive's Properties sheet; Escape.
13. Space on a file: "Selected", nothing else (a second reading of the entry here is a defect to report). Down, Up: "<name>, selected". Down, Space: "Selected, 2 selected". Ctrl+I: "…, 2 selected". Space: "Deselected, 1 selected". Ctrl+A: "N selected"; Down: "<name>, selected". Ctrl+Shift+A: "None selected"; Down: the name alone. Space on one, Enter on a folder, Backspace: the entry reads its name alone, the selection gone. Shift+Down three times: each entry reads "<name>, selected" as it is reached, nothing else; Shift+Up: the entry left reads its name alone; Ctrl+I: "…, 3 selected" (the start and two more). Down without Shift, then Shift+End: every entry from there to the last reads "selected", the earlier three still selected; Ctrl+Shift+A.

## 2. From and to the other windows (AF-1.3)

1. In AxClaude on a project, Alt+S, I: "Show current folder in submenu", Down to "AxFile"; Enter: a new AxFile window on the project folder.
2. In AxDown on a file, Alt+F, I, F: AxFile on the file's folder with the file selected. The same from AxJSON.
3. In AxGit, Alt+R, I, F: AxFile on the repository. In AxTerminal, Alt+S, I, F: AxFile on the shell's folder.
4. In AxFile, Alt+F, I: "File Explorer Ctrl+W", "AxClaude", "AxGit", "AxTerminal"; Enter on AxTerminal: a shell in the folder. Ctrl+W: File Explorer on the folder. Ctrl+Shift+W on an entry: File Explorer with the entry selected.

## 3. File operations and the entry's menu (AF-4)

1. Ctrl+Shift+N: the notice "New folder" with the field "Name"; Enter on the empty field: "Type a name", the notice stays; type `notes`, Enter: "Created notes", the focus in the list on "notes, folder".
1a. Ctrl+Shift+T: NVDA reads "New name, edit, New file.txt, selected New file.txt" (the whole name); type `todo.md`, Enter: "Renamed to todo.md", the focus on `todo.md`, an empty file. Ctrl+Shift+T, Escape: the box closes on "New file.txt", which stays. Space on `todo.md` and on `New file.txt`, Shift+F10, V: the notice "Move to new folder" saying "2 items will move into the new folder" with the field "Name"; type `bundle`, Enter: "Moved 2 items into bundle", the focus on "bundle, folder"; Enter: both files inside.
2. F2 on it: NVDA reads "New name, edit, notes, selected notes"; type `Notes`, Enter: "Renamed to Notes", the focus in the list on "Notes, folder". F2 on a file `a.txt`: the box holds "a.txt" with "a" selected, so typing replaces the name and keeps the extension; Escape: the box closes, the list reads "a.txt" again, nothing renamed. F2, Enter without typing: "Name unchanged".
3. Delete on Notes: the notice "Delete Notes?" with "It goes to the Recycle Bin with everything in it." and the buttons Delete and Cancel; Escape: nothing happens; Delete, Enter: "Deleted Notes", the focus on the next entry. Open the Recycle Bin in File Explorer: Notes is there.
4. Ctrl+Shift+C on a file: "Copied path"; paste somewhere: the full path. Space on two files, Ctrl+Shift+C: "Copied 2 paths"; paste: two lines.
5. Ctrl+Shift+N with the name of an existing entry: "Failed: There is already an entry named …". F2 with `a?b`, Enter: "A name cannot contain …", the box stays. F2 on a file and type another entry's name with a space at the end, Enter: "Reads the same as <that name>, which is already here", the box stays; Escape.
6. Ctrl+C on a file: "Copied a.txt"; Ctrl+V: "Pasted a.txt", a second file "a - 2.txt" is in the list. Ctrl+X on it: "Cut …"; Ctrl+V here: "Already in this folder"; Enter on a folder, Ctrl+V: "Pasted …", the file is in the list, and Backspace shows it gone from the folder above. Copy a file in File Explorer, Ctrl+V in AxFile: it arrives; Ctrl+X in AxFile, paste in File Explorer: it moves. Ctrl+V with text on the clipboard: "Nothing to paste". Space on two files, Ctrl+C: "Copied 2 items"; Enter on a folder, Ctrl+V: "Pasted 2 items". Space on both of them there, Delete: "Delete 2 items?" with "They go to the Recycle Bin."; Enter: "Deleted 2 items", the focus on the entry that follows them, or the one before when none follows.
7. Shift+F10 on a file: the entry's menu opens as a context menu and NVDA reads its first item, "Open Enter"; Down through it: Open with submenu, Open in Axit submenu, Cut Ctrl+X, Copy Ctrl+C, Paste Ctrl+V, Rename F2, Delete, New folder Ctrl+Shift+N, New text file Ctrl+Shift+T, Move to new folder, Compress to zip, Extract here, Select all Ctrl+A, Select none Ctrl+Shift+A, Copy path Ctrl+Shift+C, Show in File Explorer Ctrl+Shift+W, Information Ctrl+I, Properties Alt+Enter, Windows menu; Escape closes it and the focus is back on the entry. The Applications key does the same. Alt+I: the same items in the menu bar.
7a. The menu bar: Alt: "Folder"; Right: "Item", nothing opens; Right: "Drives"; Right: "Player"; Down: the Player menu opens on "Play Enter"; Escape: the menu closes and "Player" is still selected; Right: "Options" selected, nothing opens (this is the check: it used to open the next menu); Left twice: "Item"; Down: the Item menu opens on "Open Enter"; Escape, Escape: back in the list.
8. Shift+F10, then Ctrl+I: the entry's name, size and date are said and the menu stays open; Down still moves in it. From Alt+I the key is not taken (the menu bar's copy is a standard menu).
9. Shift+F10, A: the Open in Axit submenu, Editor Ctrl+E, then AxClaude, AxDown, AxJSON, AxGit, AxTerminal, AxFile; D on a `.txt` file: a new AxDown window on it; Alt+F4 brings the focus back to the entry. On a folder, D: "Not a file". T on a folder: AxTerminal on it.
10. Alt+Enter on a file: the Windows Properties sheet, read by NVDA as any dialog, with the file's name in its title; Escape closes it and the focus is back on the entry in AxFile. Alt+Enter on a folder: the folder's sheet. Shift+F10, W, C on a `.txt` file: the Windows "How do you want to open this file?" dialog; Escape closes it. Shift+F10, W, C on a folder: "Not a file". Shift+F10, W, D on a file with no program for its type: the same dialog; Enter on such a file: the same.
11. Shift+F10, U on a file: the Windows menu for it, its first item read at once; Down through it, Right into Send to and back; Escape closes it and the focus is back on the entry, nothing done. Again, and choose Open: the file opens as it would from File Explorer.
12. Shift+F10, W: the Open with submenu, Windows default, Choose a program, "No programs of your own yet", Add a program, Remove a program (with "No programs of your own yet" inside). A, Add a program: the Windows file picker titled "Choose a program or script"; pick `C:\Windows\System32\notepad.exe`: the notice "Add a program" with the field "Name" holding "notepad"; type `Notepad`, Enter: "Added Notepad", the focus back in the list. Shift+F10, W: "1. Notepad (C:\Windows\System32\notepad.exe)" after Choose a program; Enter on it with a `.txt` file: "Started Notepad" and Notepad opens the file. Space on two text files, Shift+F10, W, 1: Notepad opens with both as arguments (one window, or two, as Notepad decides). Shift+F10, W, R, 1: "Removed Notepad"; the submenu says "No programs of your own yet" again. Options, Developer, Open settings file: `programs` holds what was added.
13. On a folder `docs`, Shift+F10, Z: "Compressed to docs.zip", the focus on `docs.zip`. Again on `docs`: "Compressed to docs - 2.zip". Space on two files, Shift+F10, Z: "Compressed to <this folder's name>.zip". On `docs.zip`, Shift+F10, X: "Extracted to docs - 3" (the names `docs`, `docs - 2` being taken), the focus on that folder; Enter: `docs` inside it with the files. Shift+F10, X on a `.txt` file: "Not a zip file".

## 4. The player (AF-5)

1. Enter on the first MP3 of a chapters folder: "Playing <name>" and the sound starts. NVDA+End: "Playing <name> 0:03 / 45:30", the time moving.
2. Ctrl+P: "Paused at 0:05", the sound stops. Ctrl+P: "Playing". Ctrl+Right: "0:20" and the sound jumps. Ctrl+Left: "0:05". Ctrl+T, type `1:00`, Enter: "1:00".
3. Ctrl+Shift+Period: "Speed 1.25"; the voice is faster at the same pitch. Ctrl+Shift+Period twice: "Speed 1.75". Ctrl+Shift+Comma: "Speed 1.5". Player, Normal speed: "Speed 1". Set 1.5 again, Alt+F4, start AxFile again and play: the speed is 1.5 (Ctrl+Q says so).
4. Ctrl+Q: "Playing <name>, 1:12 of 45:30, speed 1.5". Ctrl+Shift+Right: "Playing <next name>". Ctrl+Shift+Left: "Playing <first name>". Ctrl+Shift+Left again: "First file".
5. Ctrl+T, type `45:20` (near the end), Enter; wait: "Playing <next name>" spoken on its own, the next file plays. Player, Say each file as it starts, off; the same again: the next file plays and nothing is spoken.
6. Backspace to the folder above while it plays: the sound goes on; Ctrl+P pauses it from there; Enter on another media file elsewhere: "Playing <that name>", the first queue is dropped.
7. On the last file, Ctrl+T near its end, Enter; wait: "End of folder" with the done chime; NVDA+End: the left of the status bar is empty. Ctrl+Q: "Nothing playing". Ctrl+P: "Nothing playing".
8. Enter on a video file (`.mp4`): "Playing <name>", the picture appears at the top of the window, the focus stays in the list; Ctrl+P pauses; Ctrl+Shift+Right or the end hides the picture.
9. Enter on a file Windows cannot decode (an `.opus` without the Store codec): "Cannot play <name>: …" and the next file plays.
10. Alt+Tab to another program while a file plays, let it end: whether "Playing <next>" is heard from the background; the sound carries on either way. Alt+F4 on AxFile: the sound stops.

## 6. The queue pane (AF-9)

1. Start AxFile on a folder without media: Tab, F6, Ctrl+Tab do nothing audible, the focus stays in the list (no pane yet). In a chapters folder, Enter on the second MP3: "Playing <second>", the focus stays in the list; Tab: NVDA reads "Queue list" and the item, the second file reading "<name> (playing)"; Up: the first file, plain; the files are the folder's in order. Escape: back on the entry in the folder list. F6 and Ctrl+Tab do the same as Tab; Shift+Tab goes back.
2. In the queue, Enter on the first file: "Playing <first>", the mark moves (Down then Up reads "(playing)" on it). Delete on the third file: "Removed <third>"; the list is one shorter. Delete on the one playing: "Removed <name>" and the next file plays ("Playing <next>" only if Say each file is on). Ctrl+I on a file: "<name>, 2 of 11"; on the playing one: "…, playing, 0:12 of 45:30". Ctrl+Q: "Playing <name>, …" as from the list.
3. In the folder list, Ctrl+Enter: "Playing <first>", the queue is the whole folder again. Backspace to the folder above, Space on two folders with media and Ctrl+Shift+Q: "Added 24 to the queue"; Tab: the queue has the first folder's files, then the 24, the one playing still marked; nothing changed in the sound. Ctrl+Shift+Q on a text file: "No sound or video files to add". Ctrl+Enter in a folder without media: "No sound or video files here".
4. Player, Clear queue: "Queue cleared", the sound stops, the queue reads "Queue is empty"; Ctrl+Q: "Nothing playing". Player, Show queue: the focus goes into the queue, on "Queue is empty"; Enter there reads it again; Escape back.
5. Status lines: copy a folder of some size with Ctrl+C and Ctrl+V: "Pasted <name>" as before, and the queue's last line reads "Copied <name>" (Tab, End). Space on two files, Shift+F10, Z (Compress to zip): the last line ends as "Compressed to <name>.zip", and during a long compress it reads "Compressing, 40 of 120 files" when you arrow onto it. Delete on two selected entries: the line "Deleted 2 items". A failed operation: the line "Failed: …". Player, Clear queue clears the lines too.
6. F1 while in the queue, Escape: the focus is back in the queue, not the list. Alt+F4 while something plays: the sound stops, as before.
7. Nothing is spoken on its own when a status line is added or replaced or the mark moves while you are in the folder list; in the queue, the item under you is read again only when it is the one that changed.

## 5. Text, notices, the Axit menu (AF-6)

1. Ctrl+Plus: "Text size 13" (or the next size); Ctrl+Minus back. Options, Text, Windows text size: "Windows text size".
2. Help, User guide: this guide; Escape.
3. Alt+A: the Axit menu with New window (AxFile among the apps), Recently closed (the folder of a closed AxFile window), Open windows, Open windows by type, Close all windows, Check for updates, About. About, Version: "Axit <version>".
4. Options, Developer, Copy diagnostics: "Copied diagnostics"; paste somewhere: the versions, the folder, the player's state and the log's end.
5. Close the window and start AxFile without a folder: it opens on the same folder (the last one).
