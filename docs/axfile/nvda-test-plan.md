# AxFile NVDA test plan

The files for this plan are in `manual_tests/axfile`, made and reset by `.\manual_tests\prepare.ps1 axfile`; its `_main.md` says which folder or file each section uses.

Run with NVDA before a release, on a folder with a few subfolders, text files and sound files (a folder of MP3 chapters, and one `.json` and one `.md`), after `run-axfile.ps1 C:\path\to\folder` (or `.\run.ps1 -App file <folder>`). Every step says what NVDA should read; a step that reads differently is a defect. The specification is `docs/axfile/SPEC.md` (AF-n.m). The player's and the viewer's own checks are `docs/axmedia/nvda-test-plan.md` and `docs/axpreview/nvda-test-plan.md`; section 4 here covers the hand-overs from AxFile.

## 1. Start and the list (AF-1, AF-2, AF-3)

1. Start AxFile on the folder: NVDA reads "<folder name> - AxFile window", then "N items list, <first entry>, 1 of N" (the folder is not read again). Nothing else is spoken. A folder entry reads "docs, folder".
2. Down Arrow: the next item, nothing else. Home, End: the first and the last. Up at the first: one short low note, nothing moves and nothing is spoken; Home there: the same note. End, then Down: the note; End again: the note. Home. Type the first three letters of an entry further down, quickly: NVDA reads that entry, once (not the entries starting with each letter in turn); type the same first letter twice with a pause between: the second press goes to the next name starting with it; type `zzz`: the low note, the selection unmoved. Tab: "Actions list, No actions yet, 1 of 1"; Shift+Tab: back on the entry in the folder list; F6 and Ctrl+Tab go to the Actions list, Escape back.
3. NVDA+End: the status bar: nothing on the left, the folder's full path on the right.
3a. In a folder with a hidden file and a `.gitignore` (a git repository will do): End: the last line reads "Not shown: 1 hidden, 1 starting with a period" (your counts); Enter on it: the same line; Up: the last entry. Options, General: "Show hidden files and folders" unchecked, "Show files and folders starting with a period" unchecked; check the second: the list is read again with `.gitignore` in it, the last line "Not shown: 1 hidden"; check the first: the last line is gone. Uncheck both.
4. On a folder `docs`, Enter: "docs, 5 items, <first entry>" (your count), once, not the entry twice; the title (NVDA+T) names it. Backspace: "<folder above>, N items, docs, folder", on the folder you left. Alt+Up does the same. At `C:\`, Backspace: "This PC, N items, Local Disk (C:), drive" (your label for C: if it has one), the title "This PC - AxFile"; Ctrl+I: "Local Disk (C:), <n> GB free of <m> GB"; Ctrl+Shift+N: "Choose a drive first"; Backspace: "Top"; Enter: "Local Disk (C:), N items, <first entry>". Enter on an empty folder: "<name>, No items in this folder"; Enter, Ctrl+I or F2 on that line: "No items in this folder". Ctrl+G to another folder, Alt+D and a drive's number, Alt+F, V and a favorite: each says the folder, its count and the entry the same way.
4b. Left and Right (AF-3.1). In `navigate-arrows-type-ahead-and-levels`, on `level-1-enter-me`, Right: "level-1-enter-me, 3 items, level-2-enter-me, folder" (the same as Enter); Right twice more to `you-reached-the-bottom.txt`; Right on that file: the low note, nothing opens. Left: "level-2-enter-me, 2 items, level-3-enter-me, folder"; Left until This PC; Left there: the low note. Right on a drive: its root.
5. Ctrl+I on a file: "<name>, <size>, modified <date time>"; on a folder: "<name>, folder, modified …".
6. Enter on a `.md` file: the program Windows has for `.md` opens it (Notepad, AxDown if you made it the default, or the Windows dialog that asks which program when there is none). On a `.pdf`: your PDF reader. On a file of a type nothing opens (make `x.axtest`): the Windows "How do you want to open this file?" dialog; Escape. Ctrl+E on the `.md` file: AxDown on it (Alt+A, O goes back); on the `.json` file: AxJSON.
7. Ctrl+G: the notice "Go to folder" with the field "Path" holding the current folder; type `%USERPROFILE%\Downloads`, Enter: the list is Downloads. Ctrl+G, type a file's full path, Enter: its folder with the file selected. Ctrl+G, type `C:\nope`, Enter: "Not found: C:\nope". Completion: Ctrl+G, type `C:\Win`, Down: "Windows, folder, 1 of 1" (your names), the field reads `C:\Windows\`; Right: the first entry inside, "<name>, folder, 1 of n"; Down, Up: the next and back; Up at the first: the low note. Delete the field, type `C:`, Down: "Local Disk (C:), drive, 1 of 1". Type `zzz`, Down: the low note. Type letters after a completion, Down: completes from the new text. Enter on a completed path: the list there.
8. Ctrl+O: the Windows folder picker; choose a folder: the list shows it, the focus back in the list. Folder, Open recent folder: the folders opened by command as "1. name (path)". Ctrl+N: a second AxFile window on the same folder, read as the first was; Alt+A, O, 1 goes back to the first. Ctrl+D: "Added to Favorites"; Alt+F, V: "1. <folder> (<path>)", then "Add or remove this folder Ctrl+D"; Escape, Backspace to the folder above, Alt+F, V, 1: the folder is back. Ctrl+D: "Removed from Favorites"; Alt+F, V: "No favorites yet".
9. In File Explorer, add a file to the folder; Alt+Tab back to AxFile: the file is in the list, on the entry you had, nothing spoken. F5: "Refreshed".
10. Ctrl+F, type part of a name further down, Enter: NVDA reads that entry. F3: the next match, or "Not found". Shift+F3: back.
10a. Ctrl+Shift+F: the notice "Filter" with the field "Name contains"; type part of a name shared by a few entries, Enter: "3 of N items, filter <text>, <entry>" and the entries are those alone; Down through them. Ctrl+I: the entry as before. Escape: "Filter cleared", the whole list is back on the same entry. Ctrl+Shift+F, type `zzz`, Enter: "No names contain zzz, 1 of 1"; Enter on it: "No names contain zzz"; Escape. Alt+F, S: "Sort by submenu" with Name checked, Date, Size; D: "Sorted by date", the newest file first after the folders; Ctrl+I on the first two files confirms the dates; N: "Sorted by name".
11. Ctrl+S: "Nothing to save here". F1: the Keyboard shortcuts notice; Escape closes it.
12. Delete the folder shown in File Explorer while AxFile is on it, then Alt+Tab back: the notice "Folder not found" naming it; Enter: the list shows the folder above.
12a. Alt+F, E: the Drives submenu, "1. Local Disk (C:)" (your label), the other drives, then This PC, Eject this drive, Drive properties. 1: the list is `C:\`. Alt+F, E, P: This PC with "Local Disk (C:)" selected. With a USB stick in: Alt+F, E, its number: the stick's root; Alt+F, E, E: "Ejecting <its name>", Windows' "Safe to remove hardware" notice, the list at This PC without it. On `C:\`, Alt+F, E, E: "Failed: This drive has no Eject". Alt+F, E, R: the drive's Properties sheet; Escape. Alt+D: the Go to folder notice, as Ctrl+G.
13. Space on a file: "Selected", nothing else (a second reading of the entry here is a defect to report). Down, Up: "<name>, selected". Down, Space: "Selected, 2 selected". Ctrl+I: "…, 2 selected". Space: "Deselected, 1 selected". Ctrl+A: "N selected"; Down: "<name>, selected". Ctrl+Shift+A: "None selected"; Down: the name alone. Space on two entries, Escape: "None selected", both read their names alone; Escape again: nothing. Ctrl+Shift+F, a filter, Enter, Space on an entry, Escape: "None selected", the filter still on; Escape: "Filter cleared". Space on one, Enter on a folder, Backspace: the entry reads its name alone, the selection gone. Shift+Down three times: each entry reads "<name>, selected" as it is reached, nothing else; Shift+Up: the entry left reads its name alone; Ctrl+I: "…, 3 selected" (the start and two more). Down without Shift, then Shift+End: every entry from there to the last reads "selected", the earlier three still selected; Ctrl+Shift+A.

## 2. From and to the other windows (AF-1.3)

1. In AxClaude on a project, Alt+S, I: "Show current folder in submenu", Down to "AxFile"; Enter: a new AxFile window on the project folder.
2. In AxDown on a file, Alt+F, I, F: AxFile on the file's folder with the file selected. The same from AxJSON and from AxPreview.
3. In AxGit, Alt+R, I, F: AxFile on the repository. In AxTerminal, Alt+S, I, F: AxFile on the shell's folder. In AxMedia with a file playing, Alt+Q, S, F: AxFile on its folder with the file selected.
4. In AxFile, Alt+F, I: "File Explorer Ctrl+W", "AxClaude", "AxGit", "AxTerminal"; Enter on AxTerminal: a shell in the folder. Ctrl+W: File Explorer on the folder. Ctrl+Shift+W on an entry: File Explorer with the entry selected.

## 4. Sound, video and reading: the hand-overs (AF-5)

1. Shift+Enter on `README.md`: an AxPreview window opens on it, in front, NVDA reading its title and the first line; Alt+A, O, 1 back to AxFile. Shift+Enter on `plain.txt`: the same AxPreview window shows it (no second window). Shift+F10, E (Preview) on a file: the same as the key. Shift+Enter on a folder: a new AxFile window on that folder. Shift+Enter on an `.exe`: AxPreview in front with the notice "Not a text file"; Escape.
2. In a folder of MP3 chapters, Ctrl+Enter: an AxMedia window opens, in front, "Playing <first>", the queue the folder's files; Alt+A, O, 1 back to AxFile. Ctrl+Enter again: the same AxMedia window plays from the first again. Ctrl+Enter in a folder without media: "No sound or video files here".
3. Backspace to the folder above, Space on two folders with media and Ctrl+Shift+Q: "Added 24 to AxMedia's queue" (your count), the focus stays in AxFile, the sound goes on; Alt+Tab to AxMedia: the queue holds the first folder's files, then the 24. Ctrl+Shift+Q on a text file: "No sound or video files to add". Shift+F10, Q on a chapter: "Added 1 to AxMedia's queue".
4. Shift+F10, A, M on a chapter: AxMedia plays it with the folder's others after it, in front. Shift+F10, A, P on `README.md`: AxPreview shows it. On a folder, Shift+F10, A, P: "Not a file"; Shift+F10, A, M on a folder: AxMedia plays the folder.
5. Make AxMedia the default program for `.mp3` (Settings, Apps, Default apps, AxMedia, or Open with, Always): Enter on a chapter in AxFile plays it in AxMedia, the window in front. Make AxPreview the default for `.log`: Enter on a `.log` shows it in AxPreview. Set them back if wanted.

Tab: NVDA reads "Actions list, Created temp, 2 of 2"; Up: "Operations", the header. Escape: back on `temp` in the folder list. F6 and Ctrl+Tab do the same as Tab; Shift+Tab goes back.
2. In the folder list, F2 on `temp`, type `notes`, Enter: "Renamed to notes"; Tab: the Actions list is on "Renamed temp to notes, 3 of 3" (the newest line selected while you were in the folder list); Up: "Created temp"; Up: "Operations"; Up again: the low note, nothing moves; End, Down: the note. Enter on "Created temp": the folder list, on `notes` (the folder it became), the folder said only when it is another than the one shown; Tab, Enter on "Renamed temp to notes": the same.
3. In the Actions list on "Renamed temp to notes", Ctrl+Z: "Undone: renamed back to temp", the folder list on `temp`; Tab: the line reads "Renamed temp to notes, undone"; Ctrl+Z on it: "Already undone"; Enter on it: the folder list on `temp` (where the undo put it back). Ctrl+I: "Operations, 2 of 2, <hh:mm>"; Up to the header, Ctrl+I: "Operations".
4. In the folder list, Enter on a folder, Ctrl+Shift+N `inner`, Enter, Backspace; Tab: the newest line "Created inner"; Enter: the folder list is the subfolder with `inner` selected. Backspace.
